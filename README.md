# Mission veille IKEA

Site pédagogique statique pour préparer le dossier individuel TPRA738.
Il comprend l’accueil, six étapes, les consignes et leurs attendus, ainsi que les animations et le suivi de progression.

## Dépôt sur GitHub

1. Décompressez cette archive.
2. Ajoutez son contenu à la racine de votre dépôt GitHub, en conservant le dossier `assets`.
3. Pour héberger le site avec GitHub Pages, choisissez la branche contenant les fichiers et le dossier racine (`/`).

L’archive ZIP est un paquet de transport : déposez les fichiers décompressés dans le dépôt pour publier le site.

## Utilisation

Ouvrez `index.html` pour consulter le site. Les fichiers HTML, CSS et JavaScript sont directement modifiables ; aucune compilation n’est nécessaire.
La progression est conservée localement dans le navigateur de chaque utilisateur.

Cas pédagogique non officiel. Les illustrations et le logo IKEA sont conservés pour ce cas.
